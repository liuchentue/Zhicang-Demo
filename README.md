# 知仓静态演示站

这是知仓面向中国大陆用户展示的静态产品原型。页面使用主测试账户的脱敏快照，包含今日简报、组合权重、历史记录和视频分镜预览。

它不包含登录、后端、模型调用、实时行情或视频生成，因此可以直接部署到 GitHub Pages。

## 发布

仓库已包含 GitHub Pages 工作流。推送到 `main` 分支后，在仓库 Settings → Pages 中将 Source 设为 **GitHub Actions**，工作流会发布 `docs` 中的静态站点。

## 数据边界

- 不公开邮箱、账户 ID、股数或持仓金额
- 仅展示截至 2026-08-24 的脱敏权重与简报快照
- 视频区域是分镜播放体验，不冒充已生成的 MP4 成片
